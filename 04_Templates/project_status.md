# Project Status

## Purpose

Provide a concise snapshot of the current state of the project.

Use this document when the project is sufficiently long, complex, or
collaborative that the schedule alone does not provide enough situational
awareness.

This document answers:

> **Where are we now, what requires attention, and what comes next?**

It does not replace the project plan, schedule, or decision log.

## Update Rule

Update this document only when the project state changes meaningfully or
when a status review is required.

Keep only the **current state** in this document.

Historical information should remain in its corresponding source:

- activity history → schedule;
- significant decisions → `decision_log.md`;
- project execution logic → `project_plan.md`;
- changes to project definition → `project_definition.md`.

Keep the status concise enough to understand the project state in a few minutes.
